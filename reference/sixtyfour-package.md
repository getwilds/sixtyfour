# sixtyfour: Humane Interface to Amazon Web Services

An opinionated interface to Amazon Web Services
<https://aws.amazon.com>, with functions for interacting with 'IAM'
(Identity and Access Management), 'S3' (Simple Storage Service), 'RDS'
(Relational Data Service), Redshift, and Billing. Lower level functions
('aws\_' prefix) are for do it yourself workflows, while higher level
functions ('six\_' prefix) automate common tasks.

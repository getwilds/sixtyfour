# List secrets

List secrets

## Usage

``` r
aws_secrets_list(...)
```

## Arguments

- ...:

  parameters passed on to the `paws` method

## Value

(list) list with secrets

## Note

see <https://www.paws-r-sdk.com/docs/secretsmanager_list_secrets/> for
available parameters

## Examples

``` r
if (FALSE) { # aws_has_creds() && interactive()
aws_secrets_list()
}
```

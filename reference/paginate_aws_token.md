# Paginate over list\_\* methods with NextToken

Paginate over list\_\* methods with NextToken

## Usage

``` r
paginate_aws_token(fun, target, ...)
```

## Arguments

- fun:

  (character) the name of a function to call - not the function itself

- target:

  (character) a list element to get

- ...:

  named args passed on to `fun`

# Mapping of full names of AWS services to acronyms

Mapping of full names of AWS services to acronyms

## Usage

``` r
service_map
```

## Format

### `service_map`

A data frame with 178 rows and 2 columns:

- service:

  Service name in full

- acronym:

  The acronym, from 2 to 5 characters in length

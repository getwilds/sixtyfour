# Ip Permissions generator

Ip Permissions generator

## Usage

``` r
ip_permissions_generator(engine, port = NULL, description = NULL)
```

## Arguments

- engine:

  (character) one of mariadb, mysql, or postgres

- port:

  (character) port number. port determined from `engine` if `port` not
  given. default: `NULL`

- description:

  (character) description. if not given, autogenerated depending on
  value of `engine`

## Value

a list with slots: FromPort, ToPort, IpProtocol, and IpRanges

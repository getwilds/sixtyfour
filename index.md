# sixtyfour

A science-focused, more humane R interface to AWS.

## Installation

CRAN version

``` r

# install.packages("pak")
pak::pak("sixtyfour")
```

Development version

``` r

# install.packages("pak")
pak::pak("getwilds/sixtyfour")
```

## Documentation

Go to <http://getwilds.org/sixtyfour/> for `sixtyfour` package
documentation. Go to the **Get Started** vignette to get started.

This package leans primarily on the packages
[paws](https://www.paws-r-sdk.com/) and
[s3fs](https://dyfanjones.github.io/s3fs/).
